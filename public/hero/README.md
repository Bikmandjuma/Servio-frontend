# Drop real photos here

The homepage hero carousel looks for these exact filenames and will use them
automatically the moment they exist — no code changes needed:

- `checkout.jpg` — a checkout / POS counter scene
- `inventory.jpg` — a stock-check / inventory scene
- `support.jpg` — a hardware setup / support scene

Recommended: 1200×900px or similar 4:3 photos, under ~500KB each (JPG or WEBP).

Until real photos are added here, each slide automatically shows a clean
illustrated placeholder instead — the site never looks broken either way.
